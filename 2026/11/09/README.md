## 1. 푸르닝 (Pruning, 가지치기)

> **정의:** 모델의 연산량, 파라미터 수, 메모리 사용량을 줄이기 위해 **중요도가 낮은 가중치나 신경망 층을 제거**하는 기법.

### ① 푸르닝의 3가지 형태
* **비구조적 푸르닝 (Unstructured Pruning):**
  * **원리:** 위치에 상관없이 덜 중요한 가중치를 골라 개별적으로 `0`으로 만듭니다.
  * **장단점:** 모델의 지능(성능) 보존율은 가장 높지만, 0으로 채워진 큰 행렬(Dense Matrix)을 그대로 계산하므로 **표준 하드웨어(일반 GPU)에서 실제 속도나 용량 개선이 전혀 없습니다.**
* **반구조적 푸르닝 (Semi-structured, N:M Sparsity):**
  * **원리:** 연속된 $M$개의 가중치 중 $N$개를 무조건 0으로 만드는 규칙적인 희소화 (표준 규격: **2:4**).
  * **장단점:** **NVIDIA Ampere 아키텍처(A100, RTX 3090 이상)**의 Sparse Tensor Core 전용 하드웨어 가속 규격입니다. 규칙이 엄격하여 무학습 적용 시 성능 하락이 큽니다.
* **구조적 푸르닝 (Structured Pruning / Layer Drop):**
  * **원리:** 특정 가중치 몇 개가 아니라 **어텐션 헤드(Head), 채널, 혹은 트랜스포머 레이어(Layer) 전체를 통째로 삭제**합니다.
  * **장단점:** 물리적으로 텐서 덩어리가 사라지므로 **일반 GPU에서도 즉시 속도 향상, VRAM 절감, 디스크 용량 감소**가 체감됩니다. 단, 징검다리가 끊기므로 지능 손상이 가장 치명적입니다.

### ② LLM 특화 푸르닝 핵심 개념
* **활성화 이상치 채널 (Activation Outliers):**
  * LLM은 파라미터가 커지면 특정 몇몇 입력 차원(Activation)의 숫자가 비정상적으로 거대해지는 현상이 발생합니다.
* **Wanda (Pruning by Weights and Activations):**
  * 단순히 가중치 크기($|W|$)만 보고 자르면, 가중치는 작아도 거대한 이상치 입력($\|X\|$)과 곱해져 모델 출력을 좌우하는 중요 통로가 잘려나갑니다.
  * **가중치 크기에 들어오는 입력의 크기를 곱한 값($|W| \times \|X\|$)을 점수**로 삼아 이상치 통로를 살려두는 최신 LLM 푸르닝 알고리즘입니다.
* **코사인 유사도 기반 레이어 평가:**
  * 층을 제거할 때 **"들어온 값과 나간 값의 차이($1 - \text{코사인 유사도}$)"**를 측정합니다.
  * 이 값이 0에 가까운 층은 입력값을 거의 변형시키지 않는 '하는 일 없는 층(중간 잉여 층)'이므로 제거 후보가 됩니다. (단, 입력 임베딩과 맞닿은 첫 층과 출력 헤드와 맞닿은 마지막 층은 보호 필수)

## 2. 지식 증류 (Knowledge Distillation)

> **정의:** 크고 똑똑하지만 무거운 **교사(Teacher) 모델의 지식**을 작고 가벼운 **학생(Student) 모델에게 전수**하여, 작은 모델의 추론 능력을 극대화하는 기법.

### ① 지식 증류의 두 가지 방식
* **화이트박스 증류 (Logit / Soft Label 기반):**
  * 정답 텍스트뿐만 아니라, 교사 모델이 출력하는 **각 단어별 확률 분포(Logits / Dark Knowledge)**를 Temperature(온도) 파라미터로 부드럽게 펼쳐서 학생 모델에게 KL Divergence 손실로 학습시키는 고전적 정석 방식.
* **블랙박스 / 시퀀스 레벨 증류 (Sequence-level KD / Synthetic Data):**
  * 교사 모델에게 직접 질문을 던져 **완성된 답변 텍스트(시퀀스)를 생성**하게 하고, 이를 고품질 족보(데이터셋)로 삼아 학생 모델을 지도학습(SFT)시키는 현대 LLM의 표준 방식 (Alpaca, Distil-Qwen 등).

### ② 지식 증류의 핵심 한계와 극복법
* **교사의 오답 전파 (Error Propagation):**
  * 교사가 틀린 오답과 편향까지 학생이 맹목적으로 학습하는 문제.
  * **해결책 (거부 샘플링 / Rejection Sampling):** 교사의 생성물 중 자동 채점기(`check_answer`)를 통과한 100% 정답 족보만 필터링하여 학생에게 주입.
* **데이터 기근 (Data Starvation):**
  * 교사 모델 자체가 원래 취약한 특정 도메인은 필터링을 거치면 살아남는 데이터가 거의 없어, 학생 모델도 해당 분야를 전혀 배우지 못하는 병목 발생 ("스승이 못 가르치면 제자도 못 배운다").
* **치명적 망각 (Catastrophic Forgetting):**
  * 학생 모델은 파라미터 수(뇌 용량)가 작기 때문에, 새로운 데이터를 집중 학습시키면 기존에 알고 있던 일반 상식이나 언어 능력을 덮어써서 잊어버리기 쉽습니다.

## 3. 파인튜닝과 PEFT (Full FT vs LoRA vs QLoRA)

> **정의:** 지식 증류된 데이터를 학생 모델의 두뇌에 어떤 방식으로 업데이트할 것인가에 대한 파라미터 최적화 기법.

### ① 3가지 학습 기법 비교

| 구분 | 전체 파인튜닝 (Full FT) | 순수 LoRA (Original LoRA) | QLoRA (Quantized LoRA) |
| :--- | :--- | :--- | :--- |
| **본체 모델 상태** | 16비트 (업데이트 대상) | **16비트 (동결 / Freeze)** | **4비트로 압축 (동결 / Freeze)** |
| **어댑터(USB)** | 없음 (전체 가중치 수정) | **16비트 저순위 행렬($A, B$) 추가** | 16비트 저순위 행렬($A, B$) 추가 |
| **VRAM 점유율** | 매우 높음 (옵티마이저 오버헤드) | **낮음 (가중치의 99%를 얼림)** | **극도로 낮음 (Full 대비 1/4)** |
| **학습 속도** | 느림 | **가장 빠름** | 보통 (4비트 $\leftrightarrow$ 16비트 변환 지연) |
| **정밀도 손실** | 없음 | **없음 (원본 화질 유지)** | **약 3~5% 손실 발생** (양자화 노이즈) |

### ② 핵심 엔지니어링 개념
* **LoRA의 본질:** 
  * 모델 본체 가중치 $W$는 절대 건드리지 않고, $W + \Delta W$ 형태에서 가벼운 저순위 행렬($\Delta W = B \times A$)만 학습시키는 기법.
* **가중치 병합 (`merge_and_unload`):**
  * 배포 시 어댑터를 꽂아둔 채로 서비스하면 약간의 연산 지연(Latency)이 발생하므로, 학습 완료 후 **어댑터의 가중치를 본체 뇌에 영구적으로 더해(합체) 단일 모델 파일로 만드는 작업**.

## 4. 프룬 앤 디스틸 (Prune & Distill) 연계 시너지

> **"왜 푸르닝과 지식 증류는 항상 세트로 묶여 다닐까?"**

* **푸르닝의 장점과 한계:**
  * 장점: 모델의 물리적 크기를 깎아 속도를 올리고 메모리를 줄이는 최고의 방법.
  * 한계: 뼈를 깎았기 때문에 **모델의 지능이 붕괴(성능 급락)함. 복구 학습이 필수.**
* **지식 증류의 장점과 한계:**
  * 장점: 작은 모델의 지능을 복구하고 끌어올리는 최고의 치료제.
  * 한계: 학생을 가르칠 **방대하고 비싼 고품질 라벨링 데이터셋이 필요함.**
* **두 기법의 결합 (선순환 파이프라인):**
  1. 원본 모델을 구조적으로 푸르닝하여 **작고 빠른 학생 모델의 초기 뼈대**를 생성.
  2. 아직 손상되지 않은 원본 모델을 **교사(Teacher)로 지정하여 정답 데이터(족보)를 스스로 생성.**
  3. 교사의 족보로 푸르닝된 학생 모델을 치료(복구 파인튜닝)하여 **"작은 크기 + 빠른 속도 + 원본급 지능"**을 동시에 달성.
