# Seq2Seq, LSTM 및 Attention Mechanism

## 1. 핵심 개념 요약

* **시퀀스 (Sequence)**: 순서가 있는 데이터의 나열. (예: 문장, 음성, 시계열 데이터)
* **LSTM (Long Short-Term Memory)**: 순수 RNN의 짧은 기억력(장기 의존성 문제)을 해결하기 위해 Cell State와 Gate를 추가한 모델.
* **Seq2Seq (Sequence-to-Sequence)**: 2개의 LSTM(인코더 + 디코더)을 연결하여 시퀀스 입력에서 시퀀스 출력을 생성하는 건축 구조.
* **어텐션 메커니즘 (Attention Mechanism)**: 디코더가 단어를 생성할 때, 원문(인코더)의 중요한 단어에 집중하여 고정 길이 벡터로 인한 **정보 손실(Bottleneck)**을 해결하는 기법.

---

## 2. Bahdanau vs Luong 어텐션 비교 분석

두 어텐션 기법 모두 **"학습된 지식 + 입력 문장"**의 토탈 점수(확률)가 가장 높은 단어를 순서대로 예측한다는 본질은 동일하지만, **LSTM 실행과 어텐션 연산의 시점(타이밍)**에 차이가 있습니다.

| 구분 | 바다나우 어텐션 (Bahdanau) | 루롱 어텐션 (Luong) |
| :--- | :--- | :--- |
| **발표 연도** | 2014년 (Additive Attention) | 2015년 (Multiplicative / Dot Attention) |
| **처리 매커니즘** | **[보고 계산]** 원문을 먼저 쳐다보고 LSTM 실행 | **[계산하고 보고]** LSTM을 먼저 실행하고 원문 쳐다봄 |
| **디코더 상태 시점** | 이전 시점의 은닉 상태 ($t-1$) | 현재 시점의 은닉 상태 ($t$) |
| **연산 위치** | **LSTM 입력 전**: 맥락 벡터를 LSTM 입력으로 포함 | **LSTM 출력 후**: 맥락 벡터를 LSTM 출력과 결합 |
| **연산 방식** | 덧셈 기반 (가중치 행렬 다수 사용) | 내적 기반 (Dot Product, 연산 가볍고 빠름) |
| **특징 비유** | 참고 자료(원문)를 먼저 읽고 답안을 작성 | 답안 초안을 먼저 작성한 뒤 참고 자료와 비교·보정 |

## 3. NLP 예측 방식의 본질

1. **입력 분석**: 입력 문장을 읽고 현재 맥락을 파악.
2. **점수 산출**: 사전 학습된 가중치(언어 패턴) + 입력 문장의 맥락을 결합하여 단어장 내 모든 단어의 토탈 점수 계산.
3. **결과 배출**: 토탈 점수(확률)가 가장 높은 단어를 순차적으로 하나씩 선택하여 최종 문장 완성.
---  
## 통계적 언어 모델 (SLM) vs 신경망 언어 모델 (NNLM)

### 1) 통계적 언어 모델 (Statistical Language Model, SLM)
* **개념**: 말뭉치(Corpus) 내 단어들의 **등장 빈도(Count)**를 기반으로 확률을 계산하는 클래식한 방식입니다.
* **작동**: $P(\text{단어} \mid \text{이전 단어들})$ 확률을 단순 카운트 비율로 산출합니다.
* **한계**:
  * **희소 문제 (Sparsity Problem)**: 데이터셋에 등장한 적 없는 단어나 문장 조합의 확률은 `0`이 되어 예측이 불가능합니다.
  * **의미 미반영**: 단어를 단순 기호로 취급하여 '사과'와 '배' 같은 유사 단어 간의 연관성을 이해하지 못합니다.

---

### 2) 신경망 언어 모델 (Neural Network Language Model, NNLM)
* **개념**: 단어를 고정 기호가 아닌 **밀집 벡터(Dense Vector / Embedding)**로 변환하여 신경망으로 연산하는 딥러닝 방식입니다.
* **작동**: 단어를 유사한 의미끼리 가까운 좌표를 갖도록 벡터 공간에 매핑(Word Embedding)한 뒤, 인공신경망을 통해 다음 단어의 확률을 예측합니다.
* **개선점**:
  * **희소 문제 극복**: 데이터셋에 직접 등장하지 않은 단어 조합이라도, 유사한 의미의 단어 벡터를 활용해 유연하게 확률을 예측(일반화)합니다.
  * **의미적 유사성 반영**: '사과'와 '배'처럼 비슷한 맥락에서 쓰이는 단어의 벡터 표현을 비슷하게 학습합니다.

---

### 3) 두 모델 한눈에 비교

| 구분 | 통계적 언어 모델 (SLM) | 신경망 언어 모델 (NNLM) |
| :--- | :--- | :--- |
| **핵심 원리** | 단어 등장 빈도 카운트 ($n$-gram) | 단어 임베딩 벡터 + 신경망 연산 |
| **단어 표현** | 원-핫 인코딩 / 독립된 기호 | 밀집 벡터 (의미적 유사성 반영) |
| **주요 한계** | 희소 문제 (새로운 문장 예측 불가) | 연산량 증가 및 학습 시간 필요 |
| **대표 기술** | N-gram, 카운트 기반 초기 번역기 | NNLM, RNN, LSTM, Transformer (GPT/BERT) |

---

### 4) 출력층 Softmax의 기능적 의미
* **점수 $\rightarrow$ 확률 변환**: 모델이 산출한 제한 없는 점수(Logits)를 $0 \sim 1$ 사이의 값으로 변환.
* **확률 분포 형성**: 전체 단어장 후보들의 확률 총합을 정확히 `1` ($100\%$)로 정규화.
* **결정 강화**: 지수함수($e^x$)를 활용해 높은 점수의 단어 확률을 확실하게 높여주어 최선의 단어를 선택하도록 지원.

## 5. NLP 모델 발전사: NNLM $\rightarrow$ RNN $\rightarrow$ Attention

단순 카운트 기반(SLM)을 넘어, 자연어 처리 모델들이 어떤 **한계(Problem)**를 만나고 어떻게 **개선(Solution)**해 왔는지의 핵심 흐름 정리입니다.

---

### 1) 기술 발전 흐름 한눈에 보기

| 단계 | 모델 | 해결하고자 한 핵심 문제 | 해결 방식 | 남아있는 한계 |
| :--- | :--- | :--- | :--- | :--- |
| **1단계** | **NNLM** | SLM의 희소 문제 해결 (단어 의미 반영) | 단어 임베딩을 결합(Concatenate) 후 고정 크기 레이어로 처리 | **입력 길이가 고정됨** (가변적인 긴 문장 처리 불가) |
| **2단계** | **RNN / Seq2Seq** | NNLM의 고정 길이 입력 한계 극복 | 단어를 순차적(Sequential)으로 적립/압축하여 가변 입력 처리 | **장기 의존성 & 병목 현상** (단어가 100~200개로 길어지면 초기 단어 정보가 희미해짐) |
| **3단계** | **Attention** | Seq2Seq의 초기 단어 정보 손실 문제 해결 | 디코더가 예측 시점마다 인코더의 **모든 단어 상태를 직접 조회** | 문장이 아무리 길어져도 앞부분 단어를 손실 없이 참조 가능 |

---

### 2) 핵심 문제 정의 및 전환점

* **NNLM $\rightarrow$ RNN (입력 유연성 확보)**
  * NNLM은 정해진 개수의 단어만 입력받을 수 있는 한계가 있었습니다. 
  * RNN은 입력 데이터를 순차적으로 **'적립(Cumulative Storage)'**하는 구조를 채택하여, 입력 문장의 길이에 관계없이 유동적으로 처리할 수 있게 되었습니다.

* **Seq2Seq $\rightarrow$ Attention (장기 기억 손실 극복)**
  * RNN/Seq2Seq는 모든 입력 정보를 하나의 고정된 크기(Context Vector)에 압축해야만 했습니다.
  * 이로 인해 문장이 100개, 200개 이상으로 길어지면 **초기 입력 단어들의 정보가 점점 희미해지는 문제(Information Loss / Bottleneck)**가 발생했습니다.
  * **Attention(Bahdanau / Luong)**은 디코더가 매 단어를 생성할 때마다 인코더의 전체 은닉 상태를 직접 가중치 있게 참조하게 만듦으로써 긴 문장의 정보 손실을 근본적으로 해결했습니다.
