## 1. 🎯 지도학습 vs 비지도학습 (Supervised vs Unsupervised)

### 📌 지도학습 (Supervised Learning)

* **개념**: 정답(Label)이 포함된 [문제 - 정답] 데이터셋을 모델에 학습시키는 방식입니다.
* **학습 목적**: 새로운 데이터가 입력되었을 때 정확한 정답을 예측하거나 분류하는 능력을 기릅니다.
* **LLM에서의 활용**: **SFT (Supervised Fine-Tuning)** 단계에서 활용됩니다. 사람이 정제한 high-quality 질문-답변 데이터를 이용해 챗봇의 말투와 행동 양식을 지정합니다.
* **특징**: 데이터 구축 비용이 매우 높지만, 모델의 출력 방향을 명확하게 제어할 수 있습니다.

### 📌 비지도학습 (Unsupervised Learning)

* **개념**: 정답(Label)이 없는 대량의 데이터만을 주고, 데이터 내부의 패턴이나 구조를 스스로 파악하도록 하는 방식입니다.
* **학습 목적**: 언어의 문법, 일반적 지식, 문맥 간의 연관 관계를 스스로 습득합니다.
* **LLM에서의 활용**: **Pre-training (사전 학습)** 단계에서 활용됩니다. 인터넷상의 수조 개 문서에서 '다음 단어 맞추기(Causal Language Modeling)' 방식으로 스스로 학습합니다.
* **특징**: 데이터 수집 비용이 매우 낮아 대규모 데이터셋 구축에 유리합니다.

---

## 2. 🔄 전이 학습 체계 (Transfer Learning Framework)

**전이 학습(Transfer Learning)** 이란, 한 과제(Task)에서 이미 학습된 지식과 가중치(Weights)를 가져와 다른 관련 과제에 재사용하는 **전체적인 학습 방법론**을 의미합니다.

전이 학습 프레임워크는 크게 사전 학습(Pre-training)과 미세 조정(Fine-tuning)의 2단계로 구성됩니다.

---

### 1️⃣ 사전 학습 (Pre-training)

* **단계**: Upstream Task (1단계)
* **학습 방식**: 비지도 학습 / 자기지도 학습 (Self-Supervised Learning)
* **데이터**: 정답 태그가 없는 수조 개의 거대한 데이터 (인터넷 문서, 위키피디아, 서적 등)
* **핵심 역할**: 무작위 가중치 상태의 모델에게 언어의 기본 구조, 문법, 세상에 대한 일반 지식을 수련시켜 기초 체력(Base Model)을 다집니다.
* **비유**: 의과대학 6년 공통 과정 (해부학, 생리학 등 기본 의학 지식을 익히는 단계)

---

### 2️⃣ 미세 조정 (Fine-tuning)

* **단계**: Downstream Task (2단계)
* **학습 방식**: 지도 학습 (Supervised Learning / SFT)
* **데이터**: 소량의 정제된 정답 데이터셋 (질문-답변, 요약, 감정분석 데이터 등)
* **핵심 역할**: 사전 학습으로 기본기를 다진 모델(Base Model)에 특정 목적에 맞는 정답 데이터를 주어, 원하는 과제(챗봇, 번역기, 분류기 등)를 잘 수행하도록 세부 조정(Instruction Tuning)합니다.
* **비유**: 전공의(레지던트) 과정 (기본 의학 지식을 바탕으로 내과, 안과 등 특정 전공을 집중 훈련하는 단계)

---

## 🚀 Summary: LLM 학습 파이프라인 흐름

1. **Pre-training (비지도 학습)**
* 수조 개의 원본 텍스트 수집 ➔ 다음 단어 예측 학습 ➔ 일반 지식을 가진 **Base Model** 탄생


2. **Transfer (지식 전달)**
* Base Model의 가중치(Weights)를 그대로 이어받음


3. **Fine-tuning (지도 학습)**
* 정제된 [Instruction - Answer] 데이터 적용 ➔ 사용자 지시를 잘 따르는 **Instruct / Chat Model** 완결

Word2Vec에서 시작해 ELMo를 거쳐 BERT와 GPT로 이어지는 **자연어 처리(NLP) 임베딩 패러다임의 발전 흐름**을 깔끔하게 정리해 드릴게요.

---

### 1. 1세대: 고정 단어 임베딩 (Word2Vec, GloVe)

* **개념**: 단어를 고정된 차원의 N차원 수치 벡터로 변환하는 방식입니다.
* **한계**: **동음이의어를 구분하지 못합니다.**
* "사과를 **배**로 운반한다"와 "달콤한 **배**를 먹는다"에서 **배**라는 단어는 동일한 하나의 벡터 값을 가집니다.


* **의의**: 단어 사이의 유의미한 유사도(예: `한국 - 서울 + 파리 = 프랑스`)를 계산할 수 있게 된 첫걸음이었습니다.

---

### 2. 2세대: 문맥 의존적 임베딩과 전이학습의 시작 (ELMo)

* **개념**: 단어가 쓰인 문장 전체의 흐름을 고려해 단어 벡터를 동적으로 생성합니다.
* **혁신**:
* **동음이의어 해결**: 주변 문맥을 읽어 "바다의 배"와 "과일 배"의 벡터 값을 다르게 표현합니다.
* **전이학습(Transfer Learning) 도입**: 대규모 비지도 데이터로 사전 학습(Pre-training)한 지식을 다운스트림 과제에 재사용하는 흐름을 정착시켰습니다.


* **한계**: **LSTM 아키텍처의 한계**
* 단어를 순차적으로 처리하므로 속도가 느려 병렬 학습이 불가능했습니다.
* 정방향/역방향 문맥을 독립적으로 구한 뒤 단순히 합치는 방식이라 결합이 얕았습니다.



---

### 3. 3세대: 트랜스포머 아키텍처 기반의 대성공 (BERT & GPT)

ELMo가 제시한 **"사전 학습 ➔ 미세 조정"** 프레임워크에 **트랜스포머(Transformer)** 아키텍처가 결합하면서 자연어 처리가 완전히 개편되었습니다.

* **BERT (Encoder 기반)**:
* **ELMo의 완전체 버전**입니다.
* 트랜스포머의 Self-Attention을 활용해 문장의 앞뒤 문맥을 깊은 양방향(Deep Bidirectional)으로 동시에 파악합니다.
* 텍스트 분류, Q&A, 검색 등 문맥 이해 과제에서 독보적인 성능을 발휘합니다.


* **GPT (Decoder 기반)**:
* **단방향 Causal Language Modeling**을 사용합니다.
* 이전 단어들을 보고 다음 단어를 예측하는 구조로, 문맥 이해를 넘어 **자연스러운 텍스트 생성(Generative AI)** 시대를 열었습니다.

## 1. 📐 트랜스포머의 3가지 변형 구조

### 📌 Encoder-Only (인코더 전용)

* **대표 모델**: BERT, RoBERTa
* **핵심 특징**: 문장 전체를 양방향으로 동시에 읽어 깊은 문맥을 파악합니다.
* **주요 용도**: 문장 분류, 감정 분석, 검색, 문서 임베딩 (글쓰기 ❌, 이해하기 ⭕)

### 📌 Decoder-Only (디코더 전용) ➔ ★현대 LLM의 표준

* **대표 모델**: GPT-4, Llama, Claude, Gemini, Mistral
* **핵심 특징**: 이전 단어들을 바탕으로 다음 단어를 계속해서 예측하며 이어 씁니다.
* **주요 용도**: 챗봇 대화, 코드 작성, 창작, 요약 등 모든 생성형 Task

### 📌 Encoder-Decoder (인코더-디코더)

* **대표 모델**: T5, BART, 초기 Transformer (Attention Is All You Need)
* **핵심 특징**: 입력을 해석하는 인코더와 결과를 생성하는 디코더가 결합된 형태입니다.
* **주요 용도**: 번역, 요약 등 [입력 텍스트 ➔ 출력 텍스트] 변환 Task

---

## 2. 💡 왜 현대 LLM은 Decoder-Only로 통일되었을까?

1. **대규모 데이터 학습의 압도적 유리함**
* **Decoder-Only**: 인터넷의 무수한 원본 텍스트를 정제 과정 없이 **'다음 단어 맞추기(Causal Language Modeling)'** 방식으로 즉시 사전 학습(Pre-training)에 투입할 수 있습니다.
* **Encoder-Decoder**: [입력 - 정답] 쌍으로 구성된 데이터가 필요하여 수조 단위의 데이터 학습에 불리합니다.


2. **스케일링 법칙 (Scaling Law)의 극대화**
* 모델의 파라미터 크기와 데이터 양을 늘릴수록 **Decoder-Only** 구조의 성능이 비례하여 폭발적으로 증가합니다.
* 구조가 단순하여 컴퓨팅 자원(GPU)을 효율적으로 집중할 수 있습니다.


3. **단일 메커니즘으로 모든 Task 통합**
* 단순히 '다음 단어를 예측하는 능력' 하나를 극대화했더니, 인코더 없이도 **문맥 이해, 번역, 요약, 코딩, 대화**를 하나의 모델 안에서 전부 처리할 수 있게 되었습니다.

## 💡 한 줄 요약

 인코더는 **'이해'**, 디코더는 **글쓰기**에 특화되어 발전했으며, 현대 LLM은 **Decoder-Only** 구조로 통일하여 단일 메커니즘으로 대규모 데이터를 학습시키고 모든 언어 과제를 해결하고 있습니다.
