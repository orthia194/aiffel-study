# 📌 Deep Learning & Computer Vision Core Concepts

딥러닝 프레임워크와 컴퓨터 비전(Computer Vision) 분야에서 사용되는 핵심 개념 및 연산 구조를 정리한 문서입니다.

---

## 1. Computer Vision Main Tasks

컴퓨터가 이미지를 이해하는 세밀함과 해결하려는 목표에 따른 3가지 핵심 작업 구분입니다.

| 구분 | 질문 | 결과 형태 | 설명 및 예시 |
|---|---|---|---|
| **Classification** | 이 사진은 무엇인가? | 라벨 (Label) | 이미지 전체를 보고 단일 카테고리 예측 (예: "강아지") |
| **Object Detection** | 무엇이 어디에 있는가? | Bounding Box + 라벨 | 물체의 위치를 네모 상자로 찾고 종류 식별 (예: 자율주행 장애물 탐지) |
| **Segmentation** | 물체의 정확한 경계는 어디인가? | 픽셀 단위 영역 (Mask) | 이미지의 모든 픽셀마다 클래스를 분류하여 정교하게 영역 구별 (예: 의료 MRI 장기 분할) |

## 2. CNN Core Hyperparameters & Concepts

합성곱 신경망(CNN)에서 이미지를 연산하고 특징을 추출할 때 사용되는 핵심 하이퍼파라미터 및 개념입니다.

* **Kernel & Filter (커널 / 필터)**
  * **Kernel:** 이미지 위를 슬라이딩하며 가중치 연산을 수행하는 2D 행렬 ($W$)입니다.
  * **Filter:** 하나 이상의 커널이 모인 3D 구조로, 이미지의 선, 면, 질감 등 특정한 **특징(Feature)**을 추출합니다.
* **Stride (스트라이드)**
  * 필터가 이미지를 훑고 지나갈 때 **이동하는 보폭(간격)**입니다. `Stride=2`이면 2칸씩 껑충 이동하여 출력 이미지 크기가 줄어듭니다.
* **Padding (패딩)**
  * 이미지 외곽 테두리에 임의의 값(보통 0)을 둘러싸는 포장재 작업입니다.  
  * 연산 후 **이미지 크기 축소를 방지**하고, **테두리 데이터의 손실을 막아줍니다.**
* **Pooling (풀링)**
  * 중요 정보만 남기고 이미지를 압축하는 다운스캐닝(Sub-sampling) 기법입니다. (예: Max Pooling, Average Pooling)
* **Receptive Field (수용 영역)**
  * 네트워크의 특정 뉴런 하나가 **원본 입력 이미지에서 참조하고 있는 영역의 크기**입니다. 레이어가 깊어질수록 Receptive Field가 넓어집니다.
