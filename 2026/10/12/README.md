## 1. LoRA (Low-Rank Adaptation)

LoRA는 거대한 모델의 가중치를 직접 수정하지 않고, **옆에 아주 작은 '지름길(행렬)'을 덧붙여서 그 부분만 학습**하는 기법입니다.

### ⚙️ 핵심 원리와 작동 방식

* **원본 모델 동결 (Freeze):** 수십억 개의 파라미터를 가진 원래의 가중치 행렬($W$)은 전혀 건드리지 않고 고정해 둡니다.
* **저랭크 행렬 추가 (Low-Rank Decomposition):** 원본 행렬 옆에 크기가 아주 작은 두 개의 행렬($A$와 $B$)을 새로 붙입니다. 학습이 진행되면서 이 작은 행렬들의 값($\Delta W = B \times A$)만 업데이트됩니다.
* **가중치 병합 (Merging):** 학습이 완전히 끝난 후, 원래 모델의 가중치에 새로 학습된 지름길 행렬 값을 수학적으로 합쳐버릴(Merge) 수 있습니다. 이 때문에 **실제 서비스를 배포할 때 추가적인 연산 속도 저하(Latency)가 전혀 발생하지 않는다**는 엄청난 장점이 있습니다.

## 2. QLoRA (Quantized LoRA)

QLoRA는 LoRA의 효율성에 **'극단적인 양자화(Quantization)'** 기술을 결합하여, **거대한 모델을 훨씬 더 적은 그래픽카드 메모리(VRAM)로 학습**할 수 있게 만든 혁신적인 기법입니다.

### ⚙️ 핵심 원리와 작동 방식

* **4비트 양자화 (4-bit NormalFloat, NF4):** 기존의 16비트(FP16)나 8비트(INT8)보다 훨씬 압축률이 높은 **4비트 정밀도**로 원본 모델의 가중치를 압축합니다. 정보 손실을 최소화하는 특수한 수학적 데이터 타입(NF4)을 사용합니다.
* **이중 양자화 (Double Quantization):** 양자화 과정에서 생기는 미세한 메모리까지 아끼기 위해, 양자화 상수 자체를 한 번 더 압축합니다.
* **페이지드 Optimizer (Paged Optimizers):** 학습 중 GPU 메모리가 일시적으로 부족해 터지는 현상을 막기 위해, CPU 메모리(RAM)와 GPU VRAM 사이를 실시간으로 유연하게 오가며 데이터를 관리합니다.

### 💡 QLoRA의 위력

QLoRA가 등장하기 전에는 65B(650억) 또는 70B 모델을 파인튜닝하려면 수천만 원짜리 서버용 GPU 여러 장이 필요했습니다. 하지만 QLoRA를 사용하면 **일반 소비자용 그래픽카드(예: RTX 4090 1장, VRAM 24GB) 환경에서도 70억~700억 파라미터 규모의 모델을 거뜬히 파인튜닝**할 수 있게 되었습니다.

## 📊 한눈에 비교하는 요약

| 구분 | LoRA | QLoRA |
| --- | --- | --- |
| **원본 모델 정밀도** | 16비트 (FP16 / BF16) 유지 | **4비트 (NF4)로 극단적 압축** |
| **필요한 VRAM** | 일반 파인튜닝보단 적지만, 여전히 일정 수준 이상 필요 | **매우 적음** (소비자용 GPU로 대형 모델 학습 가능) |
| **학습 성능 (정확도)** | 전체 파인튜닝과 거의 동일 | 4비트로 압축했음에도 **전체 파인튜닝 성능과 거의 대등** |
| **주요 사용 사례** | 중간 크기 모델 학습 또는 성능 저하를 0으로 만들고 싶을 때 | 제한된 하드웨어 자원으로 거대 모델(70B 이상)을 커스텀하고 싶을 때 |
